    Это предварительный план. Скачайте исходник .vibe, затем сохраните его в своём проекте Вайба по шагам ниже.

    Сохранить план в кабинете

    1. Скачайте исходный план .vibe кнопкой выше. На телефоне он появится в «Загрузках» или приложении «Файлы».
    2. Откройте кабинет, войдите и выберите свой проект Вайба.
    3. В разделе «Планы из конструктора» выберите скачанный файл, проверьте текущий проект и нажмите «Сохранить план в этом проекте».
    Открыть свой кабинет

    Файл сохранится после вашего выбора и подтверждения в кабинете. PDF — отдельная памятка для просмотра; для передачи плана нужен исходный .vibe.

    Уже есть сохранённый план Вайба?

    Можно открыть файл .vibe и добавить выбор обложки к нему. Его остальные разделы, включая личные записи, сохранятся в скачанном проекте. Просмотр примеров их не меняет.

    Открыть прежний подробный конструктор →

    Рекомендуемый порядок съёмки классики

    1. Сначала общая фотография класса.
    2. Затем компании или фотобудка.
    3. После — остальные общие кадры, которые хотите снять.
    4. В конце — портреты по одному.

    После общих кадров и своего портрета фотограф сможет отпускать по одному тех, кто уже отснялся и больше не нужен в запланированных кадрах. Так торопящимся ребятам не придётся ждать окончания всех портретов.

    Если начать с портретов, всему классу придётся оставаться до конца общих кадров. Заранее согласуйте порядок с фотографом: это рекомендация для дня классики, а не порядок разворотов в альбоме.
